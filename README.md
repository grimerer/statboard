# 능력치 보드 (해커톤 데모)

업무·개인 활동을 기록하면 능력치가 오르고, 같은 집단 안에서 100점 만점으로 환산되는 인력관리 게임화 데모예요.

- 프런트엔드: 빌드 없는 정적 페이지 (`index.html`) → Vercel 자동 배포
- 데이터: Supabase (Postgres + REST). 설정이 없거나 연결에 실패하면 로컬 시드 데이터로 동작해요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 점수·레벨 계산 로직 전체 |
| `config.js` | Supabase URL과 publishable 키 (공개용 키) |
| `supabase/schema.sql` | 테이블과 RLS 정책 |
| (DB에만 있음) | 데모 인원 24명과 최근 6개월 활동 시드. 페이지 콘솔에서 `__statboardSeed()`로 같은 데이터를 다시 만들 수 있어요 |

## 배포 흐름

`main` 브랜치에 커밋하면 Vercel이 자동으로 새 버전을 배포해요.

## 데이터 구조

- `personnel`: 이름, 계급(→ 병사/간부), 부대, 특기(고정), 담당 직무(행정/특기/지휘관), 도입 전 누적 XP
- `activities`: 활동 유형, 규모, 역할, 점수, 날짜. `is_seed = true`는 시드 데이터

## 보안 메모 (데모 단계)

로그인 없이 누구나 조회, 활동 기록, 직무 변경, 직접 기록한 활동 삭제가 가능해요.
실제 운영 전에는 Supabase Auth를 붙이고 RLS 정책을 사용자·권한별로 좁혀야 해요.
